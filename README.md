# Polyglow

Polyglow — статическое двуязычное веб-приложение для личного дневника изучения языков. Оно включает Focus-таймер, ручные занятия, календарь, серии, цели, награды и аналитику. Данные сохраняются только в `localStorage` текущего браузера.

## Локальный запуск

Приложение можно открыть двойным щелчком по `index.html`. Для проверки в условиях, близких к GitHub Pages, запустите статический сервер:

```powershell
python -m http.server 8000
```

После этого откройте `http://localhost:8000/`.

## Публикация на GitHub Pages

1. Поместите файлы проекта в корень репозитория.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**.
4. Выберите ветку `main`, каталог `/ (root)` и сохраните настройки.
5. Откройте выданную GitHub ссылку и выполните проверку ниже.

Все внутренние пути относительные, поэтому приложение работает и в подпапке вида `https://username.github.io/repository-name/`. Сборка и серверная часть не требуются.

## Проверка перед публикацией

- пройти onboarding, выбрать несколько языков и перезагрузить страницу;
- проверить RU и EN без смешивания строк;
- проверить светлую и тёмную темы;
- создать ручное занятие и завершить Focus-сессию;
- убедиться, что каждая запись появилась в дневнике и аналитике один раз;
- проверить календарь, серии, цели и детализацию аналитики;
- открыть сайт при ширине 360, 768 и 1440 пикселей;
- пройти основные действия клавишами `Tab`, `Shift+Tab`, `Enter`, `Space` и `Escape`;
- убедиться, что музыка включается только после действия пользователя.

## Основные файлы

- `index.html` — разметка приложения;
- `assets/css/styles.css` — темы и адаптивный интерфейс;
- `assets/js/app.js` — отображение и пользовательские действия;
- `assets/js/modules/storage.js` — локальное хранилище и миграции;
- `assets/js/modules/i18n.js` — словари RU/EN;
- `assets/js/modules/stats.js` — расчёты календаря, целей и аналитики;
- `assets/js/data/` — статические каталоги;
- `assets/images/` и `music.mp3` — локальные ассеты.

## Приватность

Приложение не отправляет данные на сервер. Сброс в профиле удаляет только ключ Polyglow после отдельного подтверждения.

## Безопасная передача файлов на GitHub

Не загружайте проект по одному файлу через API или текстовый редактор GitHub: в Polyglow есть текстовые файлы больше 29 КБ и более 270 SVG-флагов. Используйте обычный Git — он передаёт содержимое целиком и проверяет его по хешам.

Перед коммитом выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\verify-github-files.ps1
git status --short
```

Для первой публикации:

```powershell
git add .
git commit -m "Prepare Polyglow for GitHub Pages"
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

После загрузки повторно клонируйте репозиторий в другую папку и запустите `verify-github-files.ps1`. Если файл был обрезан или пропущен, проверка завершится ошибкой и назовёт проблемный путь.
